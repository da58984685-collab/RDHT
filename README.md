## DB 전송량(egress) 최적화 메모

- 목록·상태 조회는 필요한 컬럼만 가져옵니다. 사진(base64)·성격·특성 같은 긴 값은 평소 조회에서 제외됩니다.
- 사진은 `/api/img?k=...&v=...` 주소로 제공되며 브라우저/CDN에 1년간 캐시됩니다. 사진을 바꾸면 `v` 값(users.img_ver)이 바뀌어 새 주소가 됩니다. 서명 키는 `IMG_SECRET`(없으면 관리자 비밀번호 기반)입니다.
- 조회(GET) 응답에는 ETag 가 붙어, 내용이 그대로면 본문 없이 304 로 답합니다(브라우저가 자동 처리). 관리자 창 응답은 제외입니다.
- 화면이 숨겨진 탭에서는 상태/알림/메신저/지도 확인을 멈추고, 탭으로 돌아오면 한 번 바로 확인합니다.
- `DATABASE_URL` 은 Neon의 **Pooled connection**(호스트에 `-pooler` 포함) 주소를 쓰세요. 아니면 서버 로그에 경고가 찍힙니다.
- 되돌리려면 이전 버전의 `api/_app.js`, `api/_db.js`, `index.html` 으로 교체하세요. (추가된 `users.img_ver` 열은 남아 있어도 무해합니다.)

- 모두 `api/_event.js` 안에 있고, 이벤트를 끄면 함께 닫힙니다. 화면은 할로윈 앱 위쪽 탭(소원 · 도감 · 장터 · 귀신의 집)으로 나뉩니다.
- 새 표 2개: `ev_claims`(도감·장터·횟수 기록, 헌터당 몇 줄), `ev_house`(귀신의 집 진행 상태, 하루가 지나면 자동 삭제).

- 소원 주인은 한국 날짜 10월 22일부터 8일 동안 날마다 바뀝니다. (이벤트 기간 밖에서 '켜기'로 시험하면 같은 8일을 되풀이합니다.)
- 귀신의 집 화면은 열려 있는 동안만 3초마다 상태를 확인하고, 숨은 탭이나 닫힌 팝업에서는 멈춥니다.
- 귀신의 집 둘만의 채팅: 새 표 `ev_house_chat`(집마다 최근 30줄만 유지, 집이 정리될 때 함께 삭제). 두 참가자만 읽고 쓸 수 있으며 100자 제한 · 30초에 20회 제한. 새 글만 받아 오므로 DB 읽기가 거의 늘지 않습니다.
- 귀신의 집 출입 횟수 조작(관리자 창 '할로윈 이벤트' 카드): 하루 기본 횟수(0~20, 기본 2) 변경, 특정 헌터의 오늘 남은 횟수 지정(기본보다 많게도 가능), 오늘 횟수 전체 되돌리기. API: `GET/POST /api/admin/event/house`. 기본 횟수는 설정 `ev_house_daily` 에 저장됩니다.
- 백귀야행(이벤트가 켜진 20시~02시) 중에는 내 일반 몬스터(F~A급·오염 사냥꾼·혈월의 잔영)가 새로 생기지 않고, 이미 있던 것도 목록에서 빠지며 토벌할 수 없습니다. 잡귀만 나옵니다. 공통 S·SS급, 폭주, 괴담 몬스터는 그대로입니다. 밤이 끝나면 다시 정상 출몰합니다.
- 둘만의 대화 자동 검열: 지금 방의 선택지 이름(핵심 단어) · '1번/첫 번째' 같은 번호 · '선택지' · 위험도 언급은 메신저 검열과 같은 ▒▓░ 문자로 가려져 저장됩니다(보낸 사람 화면에도 가려진 모습). 돌려 말하는 표현까지 모두 잡지는 못합니다. 규칙은 `api/_event.js` 의 CENS_* 를 고치면 됩니다.
- 함께할 친구 고르기에는 친구의 '접속 중'(최근 2분 안에 접속) 여부가 표시되고, 접속 중인 친구가 위로 정렬됩니다.
- 이벤트를 끄면(관리자 '끄기' · 자동 종료 포함) 모든 헌터의 '도깨비 불씨'가 함께 사라집니다. 관리자 알림의 첨부 아이템 목록에 '도깨비 불씨'가 있으며, 이벤트가 꺼진 뒤에는 수령되지 않습니다.
- 잡귀는 적월문 안쪽에 절대 나오지 않습니다 (출현 · 상태 목록 · 토벌 모두에서 차단).

## 오염 경계 시스템

- 오염도 30% / 60% / 80% 가 되면 1·2·3단계가 됩니다. 단계가 오르면 화면 위에 경고가 뜨고, 지도가 점점 붉어집니다.
- 1단계 이상: 상점 가격 +10% / +20% / +30% (구매 시에만, 상점 화면에 안내 표시)
- 2단계 이상: 사냥에서 패배하면 골드를 1.5배 더 잃습니다.
- 3단계(80%+): 위험 지역(B·A급) 출입 불가. ("오염도가 높아 해당 지역에 출입할 수 없습니다.")
- 오염 사냥꾼: 2단계 6% · 3단계 12% 확률로 30분마다 등장. 공격력(헌터 최대 체력의 약 15%)·체력(헌터 공격력의 16배)이 높고 최소 10턴은 이어지도록 맞춰져 있으며, 처치하면 오염도가 8% 줄어듭니다. 잡지 않아도 불이익은 없습니다.
- 오염 사냥꾼 강화(서버 전체): 누가 오염 사냥꾼을 토벌하든 서버 토벌 횟수가 1씩 올라, 다음 사냥꾼은 체력 +5% · 공격력 +5% · 보상(경험치·골드) +8%씩 세지고(최대 20단계), 4단계마다 최소 라운드가 +1 늘어납니다(0단계 10라운드 → 20단계 15라운드). 토벌될 때마다 시스템 팝업(제목 "오염 사냥꾼이 토벌되었습니다." · 내용 "오염 사냥꾼이 강화됩니다.")이 모든 헌터에게 자동 전송됩니다. 관리자 창 "오염 사냥꾼 현황"에서 토벌 횟수·마지막 토벌 시각을 보고 자동 팝업을 켜고 끌 수 있습니다(기본 켜짐). 기록은 기존 `settings` 표에 저장되어 새 표는 없습니다.
- 혈월의 잔영: 오염 80~99% 에서만, 30분마다 2% 확률로 등장하는 희귀 몬스터. 보상이 크지만 처치 시 오염도가 올라 100%(폭주)가 될 수 있습니다.
- 두 몬스터 모두 적월문 밖에서만 나옵니다. 수치는 `api/_game.js` 상단(TAINT_*, HUNTER_CHANCE, RARE_CHANCE, SPECIAL_MON)에서 조절합니다.

## 시스템 팝업 (관리자 → 모든 헌터)

- 관리자 창 '시스템 팝업' 카드에서 이름 · 제목 · 내용(· 선택 사진)을 적고 [모든 헌터에게 전송]. 코드는 `api/_sysmsg.js`.
- 헌터 화면: 로딩 막이 위아래로 갈라져 걷힌 뒤, 네모 팝업 안에서 격자 · 빛줄기 · 커서 주변 밝아짐 효과와 함께 눈 문양(또는 보낸 사진) · 이름 · 제목 · 내용이 차례로 떠오릅니다. 문양 파일: `sysmsg-eye.png`. 동작 줄이기 설정에서는 효과 없이 바로 최종 모습이 나옵니다.

- '전송 취소'를 누르면 아직 확인하지 않은 헌터에게는 뜨지 않고, 지금 열려 있는 팝업은 닫히며 "회수되었어요" 안내가 나옵니다. 이미 확인한 헌터의 기록은 되돌리지 않습니다.
- 새 표 2개: `sys_popups`, `sys_popup_ack` (14일 지난 줄은 새로 보낼 때 정리). 사진은 관리자 창에서 480px 로 줄여 저장합니다.

- 헌터가 질문 보내기: Q&A 탭의 "+ Q&A 질문 보내기"(별도 창, Shift+Enter 줄바꿈, 하루 10개·대기 20개까지) → 관리자 Q&A 카드의 "헌터가 보낸 질문"에 뜸 → "답변하기"로 입력칸에 채워 답변을 쓰고 공개/비공개를 골라 올림(표 `qna_ask` 자동 생성). 헌터 창에는 답변 대기 / 답변 공개 / 처리됨으로 표시됩니다.

## 도깨비 불씨가 사라지는 문제 수정
- 이전에는 이벤트가 "꺼져 있다"고 판단되는 순간 모든 헌터의 불씨를 지웠습니다. 서버가 새로 뜨거나 설정을 읽는 순간에 착오가 있어도 "꺼짐"으로 보일 수 있어서 불씨가 한꺼번에 사라질 수 있었습니다.
- 이제 불씨는 ① 관리자가 이벤트 "끄기"를 눌렀을 때, ② 자동 기간이 끝난 뒤(11/6 18시 이후)에만 사라집니다. 시작 전이거나 설정을 읽지 못한 상태에서는 지우지 않습니다. 잡귀 정리도 설정을 정상적으로 읽은 뒤에만 합니다.

## 장비 전체 수리 · 전체 해제
- 기기 → 장비 화면의 "내 장비" 위에 "전체 해제"와 "전체 수리" 버튼이 있습니다. 전체 수리는 내구도가 모자란 장비를 모두(착용 여부와 관계없이) 한 번에 고치며, 개수와 총 비용이 버튼에 표시됩니다. 골드가 모자라면 아무것도 수리하지 않습니다.
